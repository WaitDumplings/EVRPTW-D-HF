# 连续客户规模的 K 条件计数候选

状态更新：该规则已由用户于2026-11-05选入方法定稿v1。下文保留分析时的结果与来源；分析入口和参数演示不等于生产接入已完成。

本轮仅在现有 Amazon 站日统计上拟合，不生成实例、不修改生成器、不运行服务器。候选用于支持 Cus300 等任意输入 N，尚未作为最终生成规则采用。

## 模型与来源

K=1+Y，Y~Poisson(λ(N))，λ(N)=log(1+exp(a+b·ln(N/100)))。使用自然对数。softplus 使 λ 在有限 N 上严格为正，避免原硬阈值将留出城市的已观测多组情形赋予零概率。K 由 Poisson 抽样后加1，不对均值 round。

完整 521 个站日中，实际 N∈[100,2000] 的354日参与拟合，站日等权。来源为上级目录 `all_station_day_tract_groups.csv`，SHA-256 `5b4b3a097123d821cadd0d5a0c38e935caa3c7d6ad5ac663c915d251704192ae`。发布的拟合系数见[客户配置](../../config/customer_profile.json)。

拟合得到 a=-3.213676259806、b=3.100844600501。这里自变量是 ln(N/100)；改写为 ln(N) 时截距变为 -17.493593365415，斜率仍为 3.100844600501。

## 使用范围

这项两参数修改保留统一N→整数K的接口，去掉硬零区间，并在本次留城比较中得到有限预测似然。它仍保留Poisson均值—方差约束：Var(K)=E[K]−1，不能宣称已经复现Cus500等规模的集中程度。Poisson定义可参阅[R官方文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/Poisson.html)。

当前经验支持范围为100–2000，N>2000不属于已校准范围。来源K是有客户tract的最终rook连通分量；允许相邻seed时，将此分布用于K_seed仍是迁移设定，生成后的K_geo另报。
